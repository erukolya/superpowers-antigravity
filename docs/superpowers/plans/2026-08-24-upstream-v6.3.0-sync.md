# Upstream v6.3.0 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the portable half of obra/superpowers v6.3.0 into this Antigravity fork and ship it as v6.3.0.

**Architecture:** Ten prose/code changes across six existing files, one ported test suite, then release chores. Each task owns exactly one file so no two tasks contend for the same text. Upstream text is taken word-for-word via `git show` from a local upstream tag ref; the four places where verbatim porting is impossible are spelled out explicitly below and must be reproduced as written here.

**Tech Stack:** Markdown skill files, Node.js (ESM), Bash test scripts, git.

**Spec:** `docs/superpowers/specs/2026-08-24-upstream-v6.3.0-sync-design.md` — the plan argues from this spec; executors read both. Where this plan and the spec disagree, the spec governs.

## Global Constraints

- **Purity gate is the release gate.** `bash tests/antigravity/test-skill-tool-purity.sh` must pass before every commit. It forbids, anywhere under `skills/`: the strings `TodoWrite`, `EnterWorktree`, `Task tool`, `Skill tool`; the platform names `Claude Code`, `Codex CLI`, `Codex App`, `Copilot CLI`, `OpenCode`, `Factory Droid`, `Gemini CLI`; and the mapping-file names `antigravity-tools`, `copilot-tools`, `codex-tools`, `gemini-tools`.
- **Word-for-word or documented.** Upstream text is ported verbatim unless this plan states a divergence. Any *additional* divergence an implementer finds necessary must be recorded in the commit message and reported to the controller — it is not a silent judgment call.
- **Never port the four "You Do Not Dispatch Subagents" blocks.** They are excluded by design (spec, *Out of Scope → Excluded: already solved, structurally*). If you see them in an upstream diff hunk, skip them deliberately.
- **This fork ships no `skills/subagent-driven-development/scripts/`.** Any ported text referencing `scripts/review-package`, `scripts/task-brief`, or `scripts/sdd-workspace` must be re-expressed natively.
- **Target version is `6.3.0`** in `plugin.json`, `package.json`, and `gemini-extension.json`.
- **No `Co-Authored-By` trailers** in any commit.
- **Do not push, tag, or open a PR.** This plan ends at local commits.

```javascript
import * as fs from 'fs';
import * as path from 'path';
```

```javascript
    return execSync('dot -Tsvg', {
```

